# Vitro FE

Frontend for the Vitro data profiling platform, built with React and TanStack Start.

## Developing

Install dependencies and start the dev server:

```bash
pnpm install
pnpm dev
```

Required environment variables are documented in `.env.example`.

## Building

Create a production build:

```bash
pnpm build
```

Preview the production build:

```bash
pnpm preview
```

## Quality

Run linting:

```bash
pnpm lint
```
